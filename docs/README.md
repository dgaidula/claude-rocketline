# Screenshots

The README references the images below. Capture them in a terminal with a **Nerd Font**
(e.g. MesloLGS NF) and a dark background, then commit the PNGs into this folder.

Tips: clear the screen / hide your shell prompt first, crop tight, keep ≤ ~1600px wide.

| File | How to produce |
|---|---|
| `hero.png` | A single status line (`danny` theme). Use a real Claude Code session, or run `bash demos/preview.sh` and shoot the first row. |
| `responsive.png` | `bash demos/responsive.sh` — the width "staircase" showing the peel order (clock → branch → repo → reset → [effort] → qualifier → context). |
| `themes.png` *(optional)* | `bash demos/showcase.sh` — `danny` vs `dark-dan` and the four cap styles. |

> Until these PNGs exist, the README image slots show a broken-image icon on GitHub — so
> capture and add them **before** pushing the repo public (each image has a text fallback nearby).
